# برايم هب — Prime Hub

صفحةُ هبوطٍ تعريفيّةٌ لشركةِ **برايم هب** للعقاراتِ التجارية.
صفحةٌ واحدةٌ ثابتة (HTML/CSS/JS) بالعربيّةِ واتّجاهِ RTL — بلا باك-إند وبلا اعتماديّات.

## المحتوى

| القسم | الوصف |
|---|---|
| الواجهة | العنوانُ الرئيسيُّ وشريطُ أنواعِ العقارات |
| ٠١ من نحن | تعريفٌ بالشركةِ وثلاثةُ مرتكزات |
| ٠٢ خدماتنا | ستُّ خدمات |
| ٠٣ أنواع العقارات | ستّةُ أنواعٍ من الأصول |
| ٠٤ لماذا برايم هب | أربعُ نقاطِ تميّز |
| ٠٥ آليّة العمل | أربعُ خطوات |
| ٠٦ تواصل معنا | بياناتُ التواصلِ + نموذجُ طلب |

## تعديلُ بياناتِ التواصل  ← الأهم

كلُّ بياناتِ التواصلِ في **مكانٍ واحد**: الكائنُ `CONTACT` في أوّلِ ملفِّ
[`assets/js/main.js`](assets/js/main.js).

```js
const CONTACT = {
  phoneDisplay : "+966 5X XXX XXXX",   // الرقمُ كما يُعرَض
  phoneDial    : "+9665XXXXXXXX",      // رقمُ الاتصال (دوليٌّ بلا مسافات)
  whatsapp     : "9665XXXXXXXX",       // الواتساب: أرقامٌ فقط، بلا + وبلا صفرٍ في البداية
  email        : "info@primehub.sa",
  address      : "المملكة العربية السعودية — الرياض",
  hours        : "الأحد – الخميس · 9:00ص – 6:00م",
  maps         : "",                   // رابطُ خرائطِ قوقل (اختياري)
  social: { x:"", ig:"", li:"", sc:"" }// اتركْ ما ليس لديك فارغاً ليختفي أيقونتُه
};
```

تعديلُ هذا الكائنِ يُحدِّثُ تلقائياً: قسمَ التواصل، والفوتر، وزرَّ الواتساب العائم،
ووِجهةَ نموذجِ الطلب، وبياناتِ محرّكاتِ البحثِ المنظَّمة (JSON-LD).

> النصوصُ الظاهرةُ في `index.html` هي قيمٌ احتياطيّةٌ لمن يُعطِّلُ الجافاسكربت.
> بعدَ اعتمادِ الأرقامِ النهائيّةِ يُستحسَنُ تحديثُها هناك أيضاً (ابحثْ عن `phoneLink` و`mailLink`).

## نموذجُ الطلب

لا يحتاجُ خادماً: عندَ الإرسالِ يُصاغُ نصُّ الطلبِ ويُفتَحُ
**واتساب** (أو **البريد** عبرَ الزرِّ الثاني) برسالةٍ جاهزة.
الاسمُ ورقمُ الجوالِ حقلانِ إلزاميّان.

## التشغيلُ محلياً

```bash
python3 -m http.server 5183
```

ثمّ افتحْ <http://localhost:5183>

## النشر

الموقعُ ملفّاتٌ ثابتة — ارفعِ المجلّدَ كما هو على أيِّ استضافة:
Netlify أو Vercel أو Cloudflare Pages أو GitHub Pages أو أيِّ استضافةٍ عاديّة.
لا خطوةَ بناءٍ ولا اعتماديّات.

بعدَ ربطِ الدومين، حدِّثْ في `index.html` وسمَي `og:image` و`og:url` بالرابطِ الكامل.

## الملفّات

```
index.html              الصفحة
assets/css/style.css    التنسيقات
assets/js/main.js       بياناتُ التواصلِ + التفاعلات
assets/img/logo.png     الشعارُ الكامل (داكن — لخلفيّةٍ فاتحة)
assets/img/logo-light.png  الشعارُ الكامل (فاتح — لخلفيّةٍ داكنة)
assets/img/mark.png     الأيقونةُ وحدَها (داكنة) — تُستخدَمُ favicon
assets/img/mark-light.png  الأيقونةُ وحدَها (فاتحة)
robots.txt
```

الشعاراتُ مُستخرَجةٌ من ملفِّ الهويّةِ الأصليِّ بدقّةِ 400dpi وبخلفيّةٍ شفّافة.
